# 應英科專題實作GPT助手

由技高教師 Shuren 免費提供，供應英科師生專題實作課程使用，支援所有可用地區。除有特殊因素外，將持續開放分享。

## 五個獨立功能

1. 主題發想：評估題目方向、背景、可行性、意義與研究方法。
2. 研究目的及RQ檢驗：檢查並改善研究目的與研究問題的對應及可執行性。
3. Proposal檢查：檢查規劃一致性與可行性，依需求提供評分。
4. 作品說明書Introduction檢查與建議。
5. 作品說明書Section II–VI檢查與建議，包含References。

回覆以繁體中文為主，必要時搭配英文術語，英文修改符合高中EFL程度。各功能可個別使用，不必依序完成。
